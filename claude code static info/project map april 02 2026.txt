# WhatSpot — Project Map

## Live Features ✅
- Discovery feed with ripple radius expansion and criteria pass ladder
- 4-way swipe interactions (right/left/up/down)
- All interactions write to exclusion list (no venue repeats in session)
- Reserve venue photo enrichment (3 photos each)
- Silent prefetch — new venues append without loading spinner
- Spots page — 5 tabs reading from user_venue_interactions
- Session memory — search history passed to recommend
- Anonymous event logging
- CartoDB Voyager map tiles
- Custom pill-shaped map markers (rating + venue type icon + color by save status)
- Chain exclusion in discovery (60+ chains)
- FOOD_DRINK_TYPES allowlist (no gyms, banks etc in discovery)
- Club → nightclub intent disambiguation in search
- Steeles Ave northern boundary cap
- 9 anchor point rotation (auth sequential, guest random)
- Guest swipe limit system (useGuestLimits.js) — gates anonymous users, nudges toward signup

## Strategic Decisions (locked)
- Search is demoted — lightweight utility only ("find a specific venue"), not a hero feature, no significant engineering investment
- Discovery + Spots + Constellations are the product story — they are one system, not separate features
- Constellations survive search demotion — they are curated imported guides, not search results
- Spots is the hero product — solves Google Maps clunkiness and Beli's cold start problem simultaneously
- Monetization: free → constellation packs ($1-3) → travel mode → data
- No subscription model, no in-app payments (revisit when restaurant density exists)
