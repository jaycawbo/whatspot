# WhatSpot — Claude Code Context

## What This App Is
AI-powered local venue discovery app (Toronto-first). Replicates the 2-hour research process of tab-switching between Google, Reddit, critics, social. Conversational search + multi-source consensus scoring. Feels like a recommendation from a credible local friend.

## Stack
- Frontend: React/Vite, deployed on Vercel
- Database: Supabase project ref rtihqiogvamfaqitmowx
- Maps: Leaflet + CartoDB tiles
- LLM: Gemini (gemini-2.0-flash for simple calls, gemini-2.5-pro for complex)
- Version control: GitHub (whatspot repo)
